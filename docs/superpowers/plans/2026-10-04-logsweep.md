# logsweep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `logsweep`, a read-only command that reports suspicious access, new persistence, instability and failure loops from recent macOS logs.

**Architecture:** One stdlib-only Python script, `bin/bin/logsweep`. A log source streams `/usr/bin/log show --style ndjson` into `Event` records; filesystem probes read crash reports, launchd plists, `install.log` and `launchd.log`. A module-level `RULES` list (log rules) and `PROBES` list (probe rules) produce `Finding` records, which an engine groups per family and a renderer prints.

**Tech Stack:** Python 3.9+ stdlib (`argparse`, `dataclasses`, `json`, `subprocess`, `unittest`). No third-party packages.

**Spec:** `docs/superpowers/specs/2026-10-04-logsweep-design.md`

## Global Constraints

- Python 3.9 floor: no `match`, no `X | Y` type syntax, no `zip(strict=)`. Use `typing.Optional`, `List`, `Dict`, `Tuple`.
- Stdlib only.
- One file: `bin/bin/logsweep`, no extension, `#!/usr/bin/env python3`, mode 755.
- Read-only: the tool never writes, deletes or changes anything outside its own stdout/stderr.
- Call the log binary as `/usr/bin/log` (absolute). `log` is also a zsh builtin.
- Every log predicate is scoped by `process` or `subsystem`. No firehose queries; no predicate that filters on `eventMessage` alone.
- No rule may depend on a value that appears as `<private>`.
- A family that could not be read prints `could not check: <reason>`, never `no findings`.
- Exit codes: 0 completed (with or without findings); 2 bad arguments, unsupported platform, or nothing readable; 130 on Ctrl-C.
- Tests live in `tools/test_logsweep.py`, fixtures in `tools/fixtures/logsweep/`. Run with `python3 tools/test_logsweep.py`. Run them under both interpreters before each commit: `/usr/bin/python3 tools/test_logsweep.py && python3 tools/test_logsweep.py`.
- Fixtures are real captured lines with usernames, hostnames, UUIDs and addresses scrubbed (`colin` → `alice`, `chuck` → `host`).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Deviations from the spec, found while verifying rules on the target Mac

The spec's verification rule says a rule with no real example is dropped, not guessed. Applying it on 2026-10-04:

| Spec rule | Outcome | Evidence |
|---|---|---|
| sshd failed / accepted logins | **Dropped** | No `sshd` events in 7 days (Remote Login is off). |
| Kernel panic | **Dropped** | No `.panic` file in `DiagnosticReports` or `Retired`. |
| Unclean shutdown | **Dropped** | No "shutdown cause" line found in 30 days. |
| Disk I/O error | **Dropped** | No example in 24h, and a `process == "kernel"` query costs 80s. |
| Thermal throttling | **Dropped** | `thermalmonitord` messages are opaque (`die N loop N is: {…}`); no readable throttling line. |
| launchd throttling | **Kept, as a probe** | Not in the unified log. It is in `/var/log/com.apple.xpc.launchd/launchd.log` (world-readable). Threshold: 3 per service in 60 min. |
| Jetsam kill, per process | **Kept, as a probe, per event** | The log query takes 38s for 24h. `JetsamEvent-*.ips` reports in `DiagnosticReports` are instant; subject is the system, not a process. |
| Failed login/unlock | **Kept, widened** | Matches `opendirectoryd` "Authentication failed" and `authorizationhost` "Failed to authenticate user". The user is `<private>`, so the subject is the reporting process. |
| sudo failures | **Kept, pending capture** | Only "a password is required" lines exist. Task 4 provokes one real failure; if no line appears, the rule is dropped. |
| Crontab changed | **Kept** | `/usr/lib/cron/tabs` is root-only, but its own mtime is readable and moves when a crontab is installed. |

Resulting v1 rules: 2 auth (log), 3 persistence (probe), 1 stability (probe), 3 waste (probe). Only the auth family queries the unified log (measured: 10s for 24h).

Dropped rules are recorded in `CLAUDE.md` in Task 7 so they are not silently missing.

## Review Focus

1. **`log`'s trailer line.** Every `log show --style ndjson` run ends with `{"count":N,"finished":1}`. Expected: ignored, not counted as a skipped line. (Task 2)
2. **The query matching itself.** `log` records its own invocation, quoting the predicate, so a message-only match fires on the tool's own run. Expected: a `process == "log"` event never matches a rule. (Task 4)
3. **Awkward filenames.** Crash reports for processes with hyphens or spaces (`Google Chrome Helper-2026-…ips`), the `Retired` and `DiagnosticLogs` subdirectories, and `install.log` lines with non-ASCII bytes. Expected: parsed or skipped, never a traceback. (Task 5)
4. **`launchd.log` shorter than the window.** It rotates by size and held about 12 hours on the target Mac. Expected: the family prints a note saying how far back it could see. (Task 5)
5. **Output not going to a terminal.** `logsweep | head` and `logsweep > file`. Expected: no ANSI escapes, a sane fallback width, and a quiet exit on a closed pipe. (Task 6)

#!/usr/bin/env python3
"""logsweep - report things worth a look in recent macOS system logs.

Read-only. Checks four families of curated rules and prints one report:

  auth       failed sudo and login/unlock attempts
  persist    new launchd plists, crontab changes, package installs
  stability  crash and diagnostic reports
  waste      respawn loops, out-of-memory events, repeat crashers

  logsweep                     # last 24h, every family
  logsweep --since 7d          # wider window (Nm, Nh or Nd)
  logsweep --family auth,waste # only these families

A family that could not be read says "could not check"; it never says
"no findings". Exit status is 0 for a completed run, 2 for an error.
"""

import argparse
import json
import os
import re
import shutil
import socket
import subprocess
import sys
import tempfile
import threading
from dataclasses import dataclass, field
from datetime import datetime, timedelta
from typing import Callable, Dict, Iterable, Iterator, List, Optional, Tuple

FAMILIES = ("auth", "persist", "stability", "waste")
DEFAULT_SINCE = "24h"

_DURATION = re.compile(r"^([1-9][0-9]*)([mhd])$")
_UNIT_SECONDS = {"m": 60, "h": 3600, "d": 86400}


def parse_duration(text):
    """'30m' / '24h' / '7d' -> seconds. Raises ValueError otherwise."""
    m = _DURATION.match(text)
    if not m:
        raise ValueError("expected a duration like 30m, 24h or 7d, got %r" % text)
    return int(m.group(1)) * _UNIT_SECONDS[m.group(2)]


def _duration_arg(text):
    try:
        return parse_duration(text)
    except ValueError as e:
        raise argparse.ArgumentTypeError(str(e))


def _family_arg(text):
    chosen = [f.strip() for f in text.split(",") if f.strip()]
    unknown = [f for f in chosen if f not in FAMILIES]
    if unknown or not chosen:
        raise argparse.ArgumentTypeError(
            "expected a comma-separated subset of %s, got %r" % (",".join(FAMILIES), text))
    return [f for f in FAMILIES if f in chosen]


def parse_args(argv):
    # The module docstring is the help text, so the two cannot drift apart.
    p = argparse.ArgumentParser(
        prog="logsweep", description=__doc__,
        formatter_class=argparse.RawDescriptionHelpFormatter)
    p.add_argument("--since", type=_duration_arg, default=parse_duration(DEFAULT_SINCE),
                   metavar="DURATION", help="window for log rules (default %s)" % DEFAULT_SINCE)
    p.add_argument("--family", type=_family_arg, default=list(FAMILIES),
                   metavar="LIST", help="comma-separated subset of " + ",".join(FAMILIES))
    p.add_argument("--no-color", action="store_true", help="disable ANSI colour")
    return p.parse_args(argv)


def main(argv=None):
    parse_args(sys.argv[1:] if argv is None else argv)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

# --- records ---------------------------------------------------------------

@dataclass(frozen=True)
class Event:
    timestamp: datetime
    process: str
    pid: int
    subsystem: str
    category: str
    event_type: str
    message: str


TS_FORMAT = "%Y-%m-%d %H:%M:%S.%f%z"


def parse_event(line):
    """One ndjson line -> Event. None for blank lines and log's own trailer
    ({"count":N,"finished":1}); ValueError for anything malformed."""
    line = line.strip()
    if not line:
        return None
    rec = json.loads(line)  # JSONDecodeError is a ValueError
    if not isinstance(rec, dict):
        raise ValueError("not a JSON object")
    if "finished" in rec and "timestamp" not in rec:
        return None
    try:
        ts = datetime.strptime(rec["timestamp"], TS_FORMAT)
    except (KeyError, TypeError) as e:
        raise ValueError("no usable timestamp: %s" % e)
    return Event(
        timestamp=ts,
        process=os.path.basename(rec.get("processImagePath") or ""),
        pid=int(rec.get("processID") or 0),
        subsystem=rec.get("subsystem") or "",
        category=rec.get("category") or "",
        event_type=rec.get("eventType") or "",
        message=rec.get("eventMessage") or "",
    )


# --- log source ------------------------------------------------------------

# Absolute path: `log` is also a zsh builtin, and PATH is not ours to trust.
LOG_BIN = "/usr/bin/log"
LOG_TIMEOUT = 120


class SourceError(Exception):
    """A source could not be read. The message is shown to the user."""


class MacLogSource:
    def __init__(self, popen=subprocess.Popen, timeout=LOG_TIMEOUT):
        self._popen = popen
        self._timeout = timeout
        self.skipped = 0

    def events(self, predicate, since_seconds):
        cmd = [LOG_BIN, "show", "--style", "ndjson",
               "--last", "%dm" % max(1, since_seconds // 60),
               "--predicate", predicate]
        # stderr goes to a file, not a pipe: nothing drains it while stdout is
        # being read, and a full pipe would stall the child.
        with tempfile.TemporaryFile("w+") as err:
            try:
                proc = self._popen(cmd, stdout=subprocess.PIPE, stderr=err,
                                   text=True, errors="replace")
            except OSError as e:
                raise SourceError("%s: %s" % (LOG_BIN, e.strerror or e))
            timed_out = []

            def expire():
                timed_out.append(True)
                proc.kill()

            timer = threading.Timer(self._timeout, expire)
            timer.start()
            try:
                for line in proc.stdout:
                    try:
                        ev = parse_event(line)
                    except ValueError:
                        self.skipped += 1
                        continue
                    if ev is not None:
                        yield ev
                code = proc.wait()
            finally:
                timer.cancel()
                if proc.poll() is None:  # Ctrl-C or an abandoned generator
                    proc.kill()
                    proc.wait()
            if timed_out:
                raise SourceError("log show timed out after %ss" % self._timeout)
            if code != 0:
                err.seek(0)
                reason = next((l.strip() for l in err
                               if l.strip() and not l.lstrip().startswith("{")), "")
                raise SourceError(("log show exited %d: %s" % (code, reason)).rstrip(": "))
```

# --- rules -----------------------------------------------------------------

SEVERITIES = ("high", "medium", "info")


@dataclass(frozen=True)
class Finding:
    rule_id: str
    family: str
    severity: str
    title: str
    subject: str
    count: int
    first_seen: Optional[datetime]
    last_seen: Optional[datetime]
    sample: str
    advice: str


@dataclass(frozen=True)
class Rule:
    id: str
    family: str
    severity: str
    title: str
    predicate: str                              # source-side filter for `log show`
    match: Callable[[Event], Optional[str]]     # subject, or None
    advice: str
    threshold: Optional[Tuple[int, int]] = None  # (count, window_minutes) per subject
    weight: Optional[Callable[[Event], int]] = None  # occurrences one event stands for


def reaches(stamps, count, window_minutes):
    """True if any span of window_minutes holds at least `count` occurrences.
    stamps is a list of (datetime, weight)."""
    stamps = sorted(stamps, key=lambda s: s[0])
    window = timedelta(minutes=window_minutes)
    start = total = 0
    for end in range(len(stamps)):
        total += stamps[end][1]
        while stamps[end][0] - stamps[start][0] > window:
            total -= stamps[start][1]
            start += 1
        if total >= count:
            return True
    return False


def one_line(text):
    return " ".join(text.split())


def make_finding(rule_like, subject, stamps, sample):
    """Build a Finding from anything with id/family/severity/title/advice."""
    times = [s[0] for s in stamps]
    return Finding(
        rule_id=rule_like.id, family=rule_like.family, severity=rule_like.severity,
        title=rule_like.title, subject=subject, count=sum(s[1] for s in stamps),
        first_seen=min(times) if times else None,
        last_seen=max(times) if times else None,
        sample=one_line(sample), advice=rule_like.advice)


class Matches:
    """Accumulates only what matched, so the event stream is never buffered."""

    def __init__(self):
        self._stamps = {}   # (rule id, subject) -> [(datetime, weight)]
        self._sample = {}   # (rule id, subject) -> first matching message

    def add(self, rule, event):
        subject = rule.match(event)
        if subject is None:
            return
        key = (rule.id, subject)
        weight = rule.weight(event) if rule.weight else 1
        self._stamps.setdefault(key, []).append((event.timestamp, weight))
        self._sample.setdefault(key, event.message)

    def findings(self, rule):
        out = []
        for (rule_id, subject), stamps in self._stamps.items():
            if rule_id != rule.id:
                continue
            if rule.threshold and not reaches(stamps, *rule.threshold):
                continue
            out.append(make_finding(rule, subject, stamps, self._sample[(rule_id, subject)]))
        return out


def family_predicate(rules):
    return " OR ".join("(%s)" % r.predicate for r in rules)

# Every pattern below was written against a real line captured from a Mac; the
# lines are in tools/fixtures/logsweep/. Match functions check the process or
# subsystem as well as the message: `log` records its own invocation, quoting
# the predicate, so a message-only match fires on the query about itself.

# sudo writes one line per failed invocation, carrying the attempt count.
_SUDO_FAIL = re.compile(r"^\s*(\S+) : (\d+) incorrect password attempts? ;")


def _sudo_failure_user(event):
    if event.process != "sudo":
        return None
    m = _SUDO_FAIL.match(event.message)
    return m.group(1) if m else None


def _sudo_failure_attempts(event):
    m = _SUDO_FAIL.match(event.message)
    return int(m.group(2)) if m else 1


def _login_failure(event):
    # The account is <private> in both messages, so the subject is the reporter.
    if (event.subsystem == "com.apple.opendirectoryd" and event.category == "auth"
            and event.message.startswith("Authentication failed")):
        return event.process
    if (event.subsystem == "com.apple.Authorization"
            and event.message.startswith("Failed to authenticate user")):
        return event.process
    return None


RULES = [
    Rule(

        title="sudo authentication failures",

class ProbeError(Exception):
    """A probe could not read its source. The message is shown to the user."""


@dataclass
class Context:
    now: datetime            # timezone-aware
    since: int               # seconds
    home: str
    root: str = "/"          # tests point this at a temporary directory
    notes: Dict[str, List[str]] = field(default_factory=dict)

    def path(self, *parts):
        return os.path.join(self.root, *[p.lstrip("/") for p in parts])

    def cutoff(self):
        return self.now - timedelta(seconds=self.since)

    def persist_cutoff(self):
        return self.now - timedelta(seconds=max(self.since, PERSIST_MIN_WINDOW))

    def note(self, family, text):
        self.notes.setdefault(family, []).append(text)

    def local(self, naive):
        return naive.replace(tzinfo=self.now.tzinfo)


def _mtime(path, tz):
    return datetime.fromtimestamp(os.lstat(path).st_mtime, tz)


def _listdir(directory):
    """Names in a directory; [] if it does not exist; ProbeError if unreadable."""
    try:
        return sorted(os.listdir(directory))
    except FileNotFoundError:
        return []
    except OSError as e:
        raise ProbeError("%s: %s" % (directory, (e.strerror or str(e)).lower()))


def recent_files(dirs, cutoff):
    """(path, mtime) for entries modified at or after cutoff."""
    out = []
    for d in dirs:
        for name in _listdir(d):
            path = os.path.join(d, name)
            try:
                when = _mtime(path, cutoff.tzinfo)
            except OSError:
                continue  # vanished between listing and stat
            if when >= cutoff:
                out.append((path, when))
    return out

# --- engine ----------------------------------------------------------------

@dataclass
class FamilyResult:
    family: str
    findings: List[Finding]
    errors: List[str]    # sources that could not be read
    notes: List[str]
    read_ok: int         # sources that were read


def run_family(family, source, ctx, rules=None, probes=None):
    rules = [r for r in (RULES if rules is None else rules) if r.family == family]
    probes = [p for p in (PROBES if probes is None else probes) if p.family == family]
    findings, errors, read_ok = [], [], 0
    if rules:
        matches = Matches()
        try:
            for event in source.events(family_predicate(rules), ctx.since):
                for r in rules:
                    matches.add(r, event)
        except SourceError as e:
            errors.append(str(e))  # a partial read is not reported as findings
        else:
            read_ok += 1
            for r in rules:
                findings.extend(matches.findings(r))
    for p in probes:
        try:
            findings.extend(p.run(p, ctx))
        except ProbeError as e:
            errors.append(str(e))
        else:
            read_ok += 1
    findings.sort(key=lambda f: (SEVERITIES.index(f.severity), -f.count, f.subject))
    return FamilyResult(family, findings, errors, list(ctx.notes.get(family, [])), read_ok)


# --- report ----------------------------------------------------------------

FAMILY_TITLES = {"auth": "AUTH", "persist": "PERSISTENCE",
                 "stability": "STABILITY", "waste": "WASTE"}
_COLORS = {"high": "31", "medium": "33", "info": "36"}
_BOLD, _DIM = "1", "2"


def _paint(text, code, color):
    return "\033[%sm%s\033[0m" % (code, text) if color else text


def _clip(text, width):
    return text if len(text) <= width else text[:max(0, width - 1)] + "…"


def _when(first, last):
    if first is None:
        return ""
    fmt = "%m-%d %H:%M"
    if last is None or first == last:
        return first.strftime(fmt)
    if first.date() == last.date():
        return "%s → %s" % (first.strftime(fmt), last.strftime("%H:%M"))
    return "%s → %s" % (first.strftime(fmt), last.strftime(fmt))


def _plural(n, one, many):
    return "%d %s" % (n, one if n == 1 else many)


def render(results, host, since_label, now, skipped, color, width):
    lines = [_paint(_clip("logsweep — %s — last %s — %s"
                          % (host, since_label, now.strftime("%Y-%m-%d %H:%M")), width),
                    _BOLD, color)]
    for res in results:
        lines += ["", _paint(FAMILY_TITLES[res.family], _BOLD, color)]
        for f in res.findings:
            row = "  %-7s %s    %s    x%d   %s" % (
                f.severity.upper(), f.title, f.subject, f.count, _when(f.first_seen, f.last_seen))
            if len(row) > width:  # shorten the subject, keep the count and times
                over = len(row) - width
                subject = _clip(f.subject, max(1, len(f.subject) - over))
                row = "  %-7s %s    %s    x%d   %s" % (
                    f.severity.upper(), f.title, subject, f.count,
                    _when(f.first_seen, f.last_seen))
            lines.append(_paint(_clip(row.rstrip(), width), _COLORS[f.severity], color))
            lines.append(_paint(_clip("          sample: " + f.sample, width), _DIM, color))
            lines.append(_paint(_clip("          check:  " + f.advice, width), _DIM, color))
        for e in res.errors:
            lines.append(_paint(_clip("  could not check: " + e, width), _COLORS["medium"], color))
        for n in res.notes:
            lines.append(_clip("  note: " + n, width))
        if not res.findings and not res.errors:
            lines.append("  no findings")
    counts = {s: 0 for s in SEVERITIES}
    for res in results:
        for f in res.findings:
            counts[f.severity] += 1
    unchecked = sum(1 for res in results if res.errors)
    summary = "Summary: %d high, %d medium, %d info · %s could not be checked · %s skipped" % (
        counts["high"], counts["medium"], counts["info"],
        _plural(unchecked, "family", "families"), _plural(skipped, "line", "lines"))
    lines += ["", _clip(summary, width), ""]
    return "\n".join(lines)


def _since_label(seconds):
    for unit, size in (("d", 86400), ("h", 3600), ("m", 60)):
        if seconds % size == 0:
            return "%d%s" % (seconds // size, unit)
    return "%dm" % (seconds // 60)


def main(argv=None, source=None, ctx=None, platform=sys.platform, out=None):
    args = parse_args(sys.argv[1:] if argv is None else argv)
    real_stdout = out is None
    out = sys.stdout if real_stdout else out
    if platform != "darwin":
        print("logsweep: %s is not supported yet" % platform, file=sys.stderr)
        return 2
    source = MacLogSource() if source is None else source
    if ctx is None:
        ctx = Context(now=datetime.now().astimezone(), since=args.since,
                      home=os.path.expanduser("~"))
    else:
        ctx.since = args.since
    try:
        results = [run_family(f, source, ctx) for f in args.family]
    except KeyboardInterrupt:
        print(file=sys.stderr)
        return 130
    color = (not args.no_color) and hasattr(out, "isatty") and out.isatty()
    width = shutil.get_terminal_size((100, 24)).columns
    report = render(results, socket.gethostname().split(".")[0], _since_label(args.since),
                    ctx.now, source.skipped, color, width)
    try:
        out.write(report)
        out.flush()
    except BrokenPipeError:
        # `logsweep | head`: the reader left. Point stdout at /dev/null so the
        # interpreter's exit-time flush does not complain either.
        if real_stdout:
            try:
                os.dup2(os.open(os.devnull, os.O_WRONLY), sys.stdout.fileno())
            except (OSError, ValueError):
                pass
        return 0
    if all(res.read_ok == 0 and res.errors for res in results):
        return 2
    return 0

## Checking logs

`logsweep` is stateless: every finding comes from a rule in the `RULES` or
`PROBES` list in the script, and nothing is remembered between runs. Tests:
`python3 tools/test_logsweep.py` (run it under `/usr/bin/python3` too — that
one is 3.9).

**Every rule is written against a real captured line**, kept scrubbed in
`tools/fixtures/logsweep/`. Do not add a rule from documentation or memory:
capture the line first. Rules that had no real example on the machine they were
written on were dropped rather than guessed — sshd logins, kernel panics,
unclean shutdowns, disk I/O errors and thermal throttling. Add them when a real
line turns up.

Three things about `log show` shaped the design:

- **`<private>` cannot be recovered.** About a quarter of log lines carry
  redacted fields. Rules match on process, subsystem, category and the fixed
  parts of the message; the failed-login rule reports the *reporting process*
  as its subject because the account name is redacted.
- **Scope every predicate by `process` or `subsystem`.** A 10-minute unfiltered
  query is 275 MB. `process == "kernel"` costs over a minute per 24h, which is
  why jetsam is read from `JetsamEvent-*.ips` reports instead. A test enforces
  the scoping.
- **A message-only match fires on itself.** `log` records its own invocation,
  quoting the predicate. Match functions check the process as well as the text.

launchd throttling is not in the unified log at all; it is in
`/var/log/com.apple.xpc.launchd/launchd.log`, which rotates by size and may
hold only a few hours. The report says how far back it could see.

`log` is also a zsh builtin. Reproduce a query by hand with `/usr/bin/log`.

The test loader sets `sys.dont_write_bytecode`: `bin/bin/` is stowed, and a
`__pycache__` there would be symlinked into `~/bin`.

Persistence findings are a hygiene signal, not a security control — they test
`mtime`, which is trivially backdated. A family that could not be read prints
`could not check`, never `no findings`.
